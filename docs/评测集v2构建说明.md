# 评测集 v2 构建说明

- 产物：`data/eval/review_set_v2.json`（50 题，题号 `REVIEWV2-01` ~ `REVIEWV2-50`）
- 生成脚本：`backend/scripts/build_review_set_v2.py`（在 `backend/` 下，`PYTHONPATH=backend` 后用项目 venv 运行）
- 旧集：`data/eval/review_set_20261104.json` **未改动**（全程只读）
- 语料快照：118 篇 / 4,232 块，`corpus.sha256 = d569003c48057bfc843fe7f97d1f42b6fa03c7cc8fce702bd736687d8d76e33a`
  （由 `scripts.prepare_review_set.corpus_snapshot(db)` 直接 import 生成，与旧集同一函数、同一序列化口径）

> 说明：本仓库同时存在另一份 v2 脚本/文档（`prepare_review_set_v2.py` / `make_review_set_v2.py`，题号 `V2-01`~`V2-50`，
> 其 items 只有 `gold_chunk_ids` 数组、没有 `gold_span/phase/doi`，且明确只用旧 109 篇文献）。
> 当前磁盘上的 `review_set_v2.json` 是本文件描述的版本（逐字段对齐旧集结构、优先使用今日新增文献）。

## 1. 字段结构（与 `review_set_20261104.json` 对齐）

顶层：`name / version / created_at / corpus{sha256,chunks,documents} / items / limitations`。

`items` 每题逐字段沿用旧集：`qid, question, gold_chunk_id, gold_document_id, gold_doc_title,
gold_page, phase, doi, gold_span, reference_answer, content_sha256, review_status, reviewer`。
在此之上追加 4 个不改变旧字段语义的标注字段，便于分层评测与统计：

| 追加字段 | 含义 |
| --- | --- |
| `gold_chunk_ids` | 与 `gold_chunk_id` 同值的单元素数组，兼容按列表读取金标准的脚本 |
| `evidence_level` | 金标准块的证据层级（guideline / review） |
| `from_new_document` | 该块所属文献是否 2026-11-14 当天新入库 |
| `qtype` | `guideline` / `review` / `relational` 三档分层 |

- `gold_span` 一律为金标准块全文（不做人工截取），`content_sha256` 为其 sha256，可据此检测块内容漂移。
- `gold_page` 取块的 `page_start`，`phase`/`doi`/`gold_doc_title` 均取自库内真实字段，未做补齐或猜测。
- `review_status` 全部为 `pending_independent_clinical_review`，`reviewer` 为 `null`。

## 2. 抽样策略

1. **只读**：全程 `SELECT`，未对 `kb_chunk` / `kb_document` 做任何写操作；旧集文件未改动。
2. **候选打分而非随机抽样**：SQL 按「字数 300–1600（中文）/ 500–2600（英文）、正文标点密度、推荐/适应证/禁忌/比较类关键词、
   参考文献污染惩罚（`DOI:`、`et al.` 计数）」打分，按文献取分数最高的若干块；命中参考文献列表或作者名单的块在打分阶段被剔除
   （最终 50 题无一为参考文献/作者名单块）。
3. **今日新增优先**：9 篇 `created_at >= '2026-11-14'` 的新文献中选用 7 篇（3 部中文指南 + 4 篇英文研究），贡献 **19 题**。
4. **避开重切块文献**：9 篇 `updated_at >= '2026-11-14' AND created_at < '2026-11-14'` 的文献一律不选；
   构建后用 SQL 复核，50 个金标准块中属于重切块文献的为 **0** 个。
5. **单篇上限 3 块**：实际最大值为 3；19 篇文献、50 个块互不重复（unique chunks = 50）。
6. **题目用临床口语改写**，不引用块标题或首句；关系型以「A 与 B 差别 / 三种做法怎么排 / 新旧版放宽了什么 / 几条途径」提问。

## 4. 语料漂移说明

- **块数口径**：任务给的现状是 4,206 块，实际库里 active 块为 **4,232 块**（118 篇）。差 26 块来自今日入库/重切块后的实际落库结果；
  本集指纹以数据库实测为准，未强行对齐 4,206。
- **不能与旧集混跑**：旧集快照为 109 篇 / 3,772 块，`corpus.sha256` 与本集不同；跨快照比较检索指标无意义。
- **块 id 稳定性**：今日 9 篇重切块文献的块 id 已变化，旧集指向它们的题会失效（本集已主动规避）。
- **可复现**：任一题只要 `sha256(gold_span) == content_sha256` 即说明该块内容未变；若不等，说明块被重切或改字，需重建该题而非沿用指标。

## 5. 已知局限

1. 金标准是**单块单正例**：同一问题在语料中可能还有其它等价正确块，命中其它块会被判为未命中，指标偏保守。
2. 问题与答案由开发者阅读原文后撰写，**未经独立临床专家复核**（`review_status` 全部为 `pending_independent_clinical_review`）。
3. 语料含大量非结直肠专科文献（减重外科、关节置换、胆囊切除、食管癌等 AI/RAG 研究），本集保留 4 道此类题以反映真实语料构成，
   但不宜用来代表结直肠专科能力。
4. 关系型仅 10 题，分层统计置信区间很宽，不足以支撑「关系型显著优于/劣于事实型」的结论。
5. 英文题 10 题全部来自今日新增的 4 篇英文文献，跨文献覆盖不足。
