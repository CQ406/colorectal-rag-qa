# 检索评测与复核报告

执行日期：2026-11-04 至 2026-11-05。固定 12 题来源可追溯开发集，语料为 109 篇上架文献、3772 个文本块；单个金标准文本块标注，尚未独立临床复核。

旧中文/英文评测集的金标准 ID 均未匹配当前语料，因此不复用历史成绩。此次固定集保留完整来源、原文片段、参考要点、内容 SHA256 和语料指纹。问题由阅读源文后整理，不属于独立临床留出集。

## 修正的问题

关键词路原先对未排序候选先做 LIMIT，同一个问题在不同扫描计划下可能得到不同候选。现在先按去重词元命中数排序，再按文本块 ID 打破平局，之后截断；并补上文献类型过滤。重复查询三次得到相同候选。

图谱原有 395 个来源 ID 全部失效。本次明确授权后，严格使用冻结清单的 24 块、13226 字符发送至项目配置的 DeepSeek API，关闭自动重试。23 块产出实体，当前 197 个实体和 136 条关系带有效来源。旧来源保留但被过滤；图谱缓存指纹包括完整实体、类型、来源和编码器，实体候选与路径每一条关系都要求有当前有效来源，在图谱候选截断前过滤；分期/类型在文本块候选截断前过滤。导入的每个成功批次会写入跨进程更新标记，运行中的 API 自动重新核对实体索引。新抽取仍待独立复核。

2026-11-04 的首轮成绩发生在这些修正之前，只作诊断记录，不能作为最终比较。以下数据来自修正后的报告；为分离图谱和重排贡献，额外补测了不带图谱的重排配置。最后修复有效关系过滤后重启后端，复跑了两组含图谱配置；其余三组代码路径未变，沿用同一冻结语料的观测值。

| 仅向量 | 0.750 | 0.833 | 0.456 | 0.281 s | 70.632 s |
| 向量＋关键词 | 0.833 | 0.833 | 0.542 | 0.719 s | 0.721 s |
| 向量＋关键词＋图谱 | 0.833 | 0.833 | 0.340 | 0.989 s | 80.558 s |

统一设置：top_k=10、召回上限50、RRF候选上限80、单文献不限流、证据等级加权关闭；图谱和重排均显式开关。向量 BGE-M3，重排 bge-reranker-v2-m3。每题的候选块、金标准名次、路径召回数量及分段耗时均保存在 JSON。

首条向量请求及重启后首条含图谱请求包含嵌入模型冷启动；首条图谱加重排还包含重排模型加载，不能拿它们和已加载模型的后续请求直接比速度。“除首条外平均耗时”是分次顺序执行的观测值，不是随机化负载测试或可靠的 P95 性能结论。

本组中，融合＋重排有 11/12 金标准进入前5，MRR@10 为约0.742；加入图谱未进一步改变这两项结果，观测平均耗时约增加0.483秒。图谱不带重排时降低排序质量，不能宣称图谱在当前题集带来提升。建议一般查询优先考虑融合＋重排，把图谱开关用于有来源的关系查询；正式默认策略需在更大独立集上验证，本轮未直接改动默认开关。

当前图谱只覆盖 23/3772 个有效文本块；本次增量抽取还主动排除了 12 个金标准块，避免围绕测试题专项补图。因此以上结果是在稀疏、尚未人工复核的图谱及来源选取开发集上的工程对比，既不能证明完整图谱没有价值，也不能用作临床效果结论。

未命中的 REVIEW-03 涉及 MRI 伪标签分割研究，建议核查跨语言检索、文本分块和多相关证据标注。不要为提高这12题成绩直接修改金标准或专门写匹配规则。

## 解释范围与人工复核

Recall 表示预先指定的一个金标准块是否出现，不是医学答案准确率。其他正确块未全部标注，漏掉金标准不一定等于无法作答；反之召回成功也不证明答案正确。参考要点、自动抽取关系和许可仍需相应领域人工核对。

本轮没有向外部模型批量发送这份问答集，也没有用模型裁判冒充专家结论。生成质量、引用支持关系、证据不足拒答、适用人群和数值正确性请使用 [问答人工复核工作表](问答人工复核工作表.md) 逐题记录。

复现（backend目录）：

```powershell
python -m scripts.prepare_review_set                 # 保留现有冻结集
python -m scripts.run_review_ablation                # 五组本地检索，不调用外部生成模型
python -m scripts.run_review_ablation --label hybrid_rerank
```

机器记录：`data/eval/review_set_20261104.json`、`review_ablation_20261105.json`、`graph_source_audit_20261105.json`、`graph_current_build_20261105.json`。语料改变时脚本拒绝继续使用不匹配的冻结集。

## 图谱扩图实验（2026-11-08）

### 背景

此前的复核发现图谱只覆盖 23/3772 个块（0.6%），且 `graph_weight=0.6` 时
在 12 题冻结集上把 MRR 从 0.542 拖到 0.340。为判断"是覆盖不足还是图谱本身无益"，
先对**指南/共识**做增量抽取（方案 C），再重新评测。

### 扩图范围与代价

| 项 | 值 |
|---|---|
| 抽取范围 | 仅指南/共识（30 篇），长度 300–1500 字的块 |
| 抽取块数 | 919 |
| 耗时 | 5,101 秒（约 85 分钟，断点续跑） |
| LLM 解析失败 | 3 / 919（0.3%，跳过并告警） |
| 图谱规模 | 1,556 节点 / 1,500 关系 → **4,156 节点 / 5,600 关系** |
| 已抽取实体类型 | procedure 777、metric 775、exam 656、treatment 456、disease 432、complication 389、anatomy 356、drug 315 |
| 有效来源块 | 23 → **898 / 3,772 = 23.8%** |
| 有有效来源的实体 | 197（12.7%）→ **3,173（76.3%）** |

遗留：仍保留 395 个旧语料的失效来源 ID（查询时被过滤，不影响结果）。

### 结果（同一 12 题冻结集，top_k=10）

| 配置 | R@5 | R@10 | MRR@10 |
|---|---:|---:|---:|
| 仅向量 | 0.750 | 0.833 | 0.456 |
| 向量＋关键词 | 0.833 | 0.833 | 0.542 |
| 向量＋关键词＋图谱（**扩图前，权重 0.2**） | 0.833 | 0.833 | 0.535 |
| 向量＋关键词＋图谱（**扩图后，权重 0.2**） | 0.750 | 0.833 | **0.558** |
| 向量＋关键词＋图谱（**扩图后，权重 0.6**） | 0.667 | 0.833 | **0.386** |
| 向量＋关键词＋重排 | 0.917 | 0.917 | 0.742 |
| 向量＋关键词＋图谱＋重排 | 0.917 | 0.917 | 0.742 |

### 逐题变化（权重 0.2，hybrid → hybrid_graph）

12 题中只有 3 题名次改变：

| 题号 | hybrid | +图谱 | 判断 |
|---|---|---|---|
| REVIEW-04 | 2 | 6 | 变差（掉出前 5） |
| REVIEW-11 | 3 | 1 | 变好 |
| REVIEW-12 | 3 | 5 | 略差（仍在第 5） |

### 结论

1. **覆盖从 0.6% 提到 23.8% 后，图谱仍没有稳定增益**：MRR +0.016，但 R@5 少命中 1 题；
   只有 3/12 题名次变化，**12 题里 ±1 题就是 0.083，属噪声范围**，不足以宣称提升。
2. **权重 0.6 依旧有害**：扩图后高权重把 MRR 压到 0.386，比不用图谱更差。
   说明问题不只是覆盖度，图谱候选与问题相关性偏弱。
3. **加重排后图谱完全无差异**（均 0.742）：重排已经把图谱那点信号抹平。
4. 因此保持 `graph_weight=0.2`（中性），**不回调到 0.6**；图谱作为可插拔路径保留。
5. 要证明图谱价值，需要：更大的独立题集（12 题太少）、覆盖全语料（约 1,764 块可抽，
   按 11 秒/块约 5.4 小时）、以及**面向关系型问题的子集**（当前题集大多是"怎么处理"，
   本就该由文本块回答，图谱没有发挥空间）。

> 注意：报告中 `graph_source_audit` 原本抄的是 11-05 的固定文件，
> 扩图后仍显示 23/1556，会误导读者；已改为运行时实时核对。
