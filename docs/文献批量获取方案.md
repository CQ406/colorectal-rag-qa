# 文献批量获取方案（针对本项目缺口）

---

## 一、先算缺口：只需要 11 篇

| 项 | 现况 | 目标 | 缺口 |
|---|---|---|---|
| 合计文献 | 109 | ≥120 | **11 篇** |
| 中文 | 75 | ≥80 | **5 篇** |
| 英文 | 34 | — | — |

11 篇的量，**不需要写爬虫、也不需要搭下载系统**。半天内可以补齐。

---

## 二、三条通道，按可行性排序

| 通道 | 能拿到什么 | 批量能力 | 合规性 | 建议 |
|---|---|---|---|---|
| **Europe PMC 全文 XML** | 英文 OA 全文（JATS XML） | 强（REST API，可脚本） | ✅ 明确开放获取 | **英文首选** |
| 出版商直链 PDF | 英文 OA PDF | 中（逐篇拼 URL） | ✅ | 备选 |
| PMC OA 打包下载 | 英文 OA tar.gz | 强（官方批量子集） | ✅ | 大批量时用 |
| 中文指南官网 / 医学会 | 中文指南 PDF | 弱（逐篇） | ✅ | **中文首选** |
| 学校图书馆（知网/万方） | 中文论文 PDF | 中（机构 IP 内） | ✅ 订阅授权范围内 | 中文论文 |
| 文献传递（CALIS/NSTL） | 单篇 | 弱 | ✅ | 缺哪篇补哪篇 |
| 爬知网/万方 | — | — | ❌ 违反服务条款，有封 IP 与法律风险 | **不要做** |

> 结论：**英文走 API，中文走官网与图书馆**。不要为 11 篇文献写爬虫。

## 三、实测结论（2026-10-26 本机验证）

| 通道 | 结果 |
|---|---|
| `https://europepmc.org/articles/PMCxxxx?pdf=render` | **403 Forbidden** —— 有反爬，脚本拉不到 |
| 出版商直链（如 link.springer.com、bmccancer） | **200**，可下载 PDF |
| `https://www.ebi.ac.uk/europepmc/webservices/rest/{PMCID}/fullTextXML` | **200**，82 KB 完整 JATS 全文 ✅ |
| PMC OA 服务 `oa.fcgi?id=PMCxxxx` | 部分文章 404（不在 OA 子集内） |
| Europe PMC 检索 API | **200**，`OPEN_ACCESS:y AND HAS_PDF:y` 命中 30,077 条 |

**关键发现**：Europe PMC 的 PDF 渲染链接对程序不可用，但**全文 XML 稳定可用**。
而 XML 其实比 PDF 更适合本项目——见下节。

---

## 四、为什么不下载 PDF，而是下 XML

| 维度 | PDF | JATS XML |
|---|---|---|
| 章节结构 | 抽取后丢失层级，切块只能按长度硬切 | `<sec>` 自带层级，**直接映射本项目 `##` 章节切分** |
| 文字质量 | 字体缺 ToUnicode 时抽出 `!"#$%` 乱码（本项目踩过 2 篇） | 纯文本，无字体问题 |
| 表格/图注 | 常丢失或错位 | 有 `<table-wrap>` `<caption>` 可单独取 |
| 可脚本化 | 反爬 + 各家排版差异 | 单一标准格式 |

所以英文文献**优先 XML → Markdown**，而不是 PDF → Markdown。

## 五、可直接用的脚本

已写好并实测通过两个脚本（`backend/scripts/`）：

### `fetch_oa_fulltext.py` —— 英文，推荐

```powershell
cd D:\AI\RAG_project\backend
$env:PMC_QUERY = 'TITLE_ABS:"colorectal" AND TITLE_ABS:"anastomotic leak"'
& "D:\deep seek test\rag-venv\Scripts\python.exe" scripts\fetch_oa_fulltext.py --limit 10
```

- 检索 `OPEN_ACCESS:y AND SRC:PMC`（只有 PMC 收录的才有全文 XML）
- 逐篇取 `fullTextXML` → 用 lxml 解析 → 生成与 `manual_import.parse_markdown` **完全兼容**的 Markdown
- 输出到 `data/incoming_md/`，同时写 `manifest.csv`（pmcid / doi / 章节数 / 字符数 / 状态）
- 质量闸门：字符数 < 2000 或章节数 < 2 判为不合格（多数是「只有摘要没有全文」的记录）

实测输出样例：

```
**期刊**：Cureus
**年份**：2026
**DOI**：10.7759/cureus.117951
**语种**：en

## Abstract
...
## Introduction and background
...
## Review
...
## Conclusions
```

### `fetch_oa_papers.py` —— 英文 PDF 备选

只对**出版商直链**有效（Europe PMC 渲染链接会 403），带同样质量闸门与 manifest。

### 检索式写法（踩过的坑）

**太松的例子**（命中纳米颗粒、糖尿病等无关高被引文章）：

```
(colorectal OR rectal) AND (perioperative OR ERAS)
```

**推荐**：限定到标题/摘要字段，且每个主题单独跑

```powershell
$env:PMC_QUERY = 'TITLE_ABS:"colorectal" AND TITLE_ABS:"enhanced recovery"'
$env:PMC_QUERY = 'TITLE_ABS:"colorectal" AND TITLE_ABS:"anastomotic leak"'
$env:PMC_QUERY = 'TITLE_ABS:"rectal" AND TITLE_ABS:"neoadjuvant"'
$env:PMC_QUERY = 'TITLE_ABS:"colorectal" AND TITLE_ABS:"laparoscopic"'
```

> Windows PowerShell 会吞掉内层双引号，所以脚本支持用环境变量 `PMC_QUERY`
> 传检索式，避免 `TITLE_ABS:"..."` 被拆成多个参数。

## 六、中文文献怎么办（缺口 5 篇，实际建议补 6 篇）

中文没有可用的批量接口，但 5 篇完全手工可完成。优先顺序：

1. **国家卫生健康委 / 医政司官网**：诊疗规范、临床路径原文 PDF，免费、权威、可直接引用
2. **中华医学会各分会 / 中华系列期刊官网**：部分指南提供免费 PDF 或 HTML 全文
3. **学校图书馆的知网、万方账号**（机构 IP 或 VPN 内）：期刊论文 PDF 正版下载
4. **文献传递**（CALIS / NSTL / 校图书馆）：单篇申请，通常 1–2 天
5. 指南聚合站点（如医脉通）注册后可下指南，注意核对是否为官方原文

**不要做**：写爬虫抓知网。除了违反服务条款和封 IP，毕设答辩被问到数据来源合规性时也无法解释。

## 七、入库衔接（现有链路可直接复用）


无需为英文单独写 ETL —— 因为 `detect_language` 会按标题/正文判定为 `en`。

中文 PDF 走原有链路：

```powershell
& "D:\deep seek test\rag-venv\Scripts\python.exe" scripts\batch_convert_new_pdfs.py
```

## 八、必须保留的质量闸门

踩过的两个坑，都要在入口拦住：

1. **PDF 字体缺 ToUnicode** → 抽出 `!"#$%` 乱码
   检查：`pymupdf` 抽文本后统计字符数，中文文档还要数汉字个数（< 200 汉字判失败）
2. **只有摘要没有全文** → 入库后块数极少、答非所问
   检查：字符数下限 + 章节数下限（脚本里已实现）
