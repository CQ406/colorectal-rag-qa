## 六、已知副作用（必须知道）

导入时按**标题去重**：如果新文件的标题与库内已有文献相同，会走"更新"分支
（删旧块 → 重建块），该文献的文本块 id 会变。

本次补语料已因此重切了 **9 篇**旧文献，直接后果是：

- 旧评测集（`review_set_20261104.json`）里指向这些文献的金标准块 **id 已失效**
- 该冻结集的语料指纹也不再匹配（109 → 118），脚本会拒绝复用

因此 v1 只能作为历史记录；新评测集必须基于当前 118 篇重建（已在做）。
补最后 2 篇中文属于**纯新增**，只要标题不与现有文献重复，就不会再触发重切。
